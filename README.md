# C2A / C9：衡量 AGI 的认知能力 — ReCal 元认知校准的重测信度基准

**作者：** LiRuixiang
**赛道：** Track 2 — Metacognition（元认知）
**日期：** 2026-10-05

## 项目简介

本作品围绕挑战「C2A / C9：衡量 AGI 的认知能力」完成，提出并实现了一个新的基准 **ReCal**（**Re**liability of **Cal**ibration）——测量模型自报确信度这一**测量本身的可靠性**，即同一道题重复问，模型给出的自信是否稳定。

它把「校准」拆成两件常被混为一谈的事：**效度**（它说的确信度准不准，现有 benchmark 已做得很充分）与**信度**（这个测量稳不稳，此前没人检验过）。本基准以信度为主体：同一道题独立重复问 N=10 次，用 ICC（组内相关系数）区分「反映题目间真实差异的信号」与「随机噪声」。

## 核心发现（基于 deepseek-chat，550 条真实记录）

- **效度极高、信度很差**：ECE = **0.0025**（校准分 0.9975，看起来"元认知已被解决"），但同一批题重复 10 次的 **ICC 仅 0.3663**（poor，"良好校准"其实是测量噪声的假象）。
- **温度解释了大半抖动**：把 `temperature` 压到 0 后 ICC 升到 **0.819**（good）；难题组 ICC 低至 **0.0612**。
- **天花板效应**：准确率 **100%**，91.6% 的确信度报满分——题目对前沿模型太简单，测量被推到上限。
- **真实数据暴露 2 个判分 bug**（`国际儿童节（又称六一国际儿童节）`、`30万`），均为"模型答对但被判错"，已修并留成回归用例。
